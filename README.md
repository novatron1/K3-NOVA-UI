# NovaMind UI presentation prototype

This release is a presentation prototype that uses synthetic fake-host data.
It is not connected to Nova, Kimi, Qwen, tools, ledgers, permissions, evidence,
or the sandbox.

Voice capture is unavailable by default. Message text and code are inert and are
never executed. Browser persistence and telemetry are disabled for content.

## Local preview

Run `npm.cmd run dev` to start the local preview.

Real host integration requires a new reviewed specification and plan.
